# 口袋教师 · 前端版式短规

画风、色彩和字体以大卫锁定的官网规范为准。本文件只记前端版式，以后写首页及同类营销页都按这里做。

## 首屏

- 英雄插画铺满视口（整屏画布），不要左侧文案栏。
- 标题和 CTA 放在画布下方，不压在图上（顶栏除外）。
- 首屏底部必须有柔和溶白：插画下沿用彩铅笔触溶进白底，可带一点点奶油纸色或 `#D5E6E8`，不要粉色轨，禁止硬切白边。
- 溶白至少约占主图下三分之一（`.canvas::after` 高度约 36%）。
- 溶白结束之后、标题出现之前，要再留一段空白，不要标题马上接上。
- 参考 underdog 的淡出和留白节奏，不要搬他们的角色、粉红侧轨、彩虹字、白狗、产品分栏、拼布深度视差或原句。

## 大底图动效

- 主图、分节插画、收尾插画：鼠标移上去做轻微分层跟随，近多远少，缓动要软。
- 画面略放大，以免跟随时空出边缘。
- 系统开了「减少动态」（`prefers-reduced-motion: reduce`）或没有精细指针时，画面保持静止。
- 先挂主图；分节和收尾等对应图位就绪后再挂同一套动效。不要做成 underdog 那种拼布深度视差。

## 前段文字

- 标题、导语、按钮作为一组整体居中（`--measure: 40rem`），不是「收栏后栏内左齐」。
- 标题仍用 Gochi Hand（中文回退 Noto Serif SC）：大约 64–112px，行距约 1.02，再大、再紧一点。
- 导语和按钮不改手写——中英切换时 Gochi 没有中文会掉字。
- 导语略放大，墨色用 `#4A4844`，字体仍是 Atkinson / Noto Sans SC。
- 按钮改圆角胶囊，字仍用 Atkinson / Noto Sans SC，颜色仍是青绿底和墨色描边。

## 首屏以下：居中栏，不要平铺

- 首屏以下内容收入居中栏，两侧留轨，不要贴齐视口平铺。
- 侧轨 `--rail: clamp(28px, 8vw, 112px)`，栏宽 `--content: 1080px`。
- 章节之间要有独立空白，下一节标题单独居中出场，再出现该节内容。不要把前段和评价卡挤在同一屏。
- 评价卡做成和 gakku 一样的横滑：桌面、窄屏都只露出一张完整卡和下一张的边，能左右滑，不要并排钉死。每张在头像下加名字，站点排字、不画进图。不要搬五星和身份行。三张先用 Leo / 里奥、Maya / 玛雅、Owen / 欧文。不做评价墙。
- 演示动画放在溶白后的居中栏、文案下面居中，不要做成左字右视频。片长和预算听 Roy，成片未交前不挂空窗。
- 页脚前可做整幅收尾插画：整幅彩铅，呼应开头但不要再画游乐场。吉祥物仍是通体奶油小机器，像为小朋友准备礼物——可戴软软的红帽子，周围是礼物和小朋友，不要画成真人白胡子圣诞老人，场景里不另画产品，字不进图。这张允许画小朋友面部。画幅 16:9（建议至少 1920×1080）。图资出图、大卫过后再挂，先不占位。
- 叠卡仍是上拉叠卡，落在同一条侧轨里。文案落在白底上，插图边缘柔化溶进白底，不要整块奶油底去对白页，也不要拆成左栏右图。窄屏图在上、文案在卡内图下，图下沿同样溶进白底。文案保持短：标题加一句正文。
- 顶栏仍贴视口左右边缘，不受此栏约束。

## 不要做的

- 不要把内容拉满视口宽。
- 不要在页面两侧加粉红或彩色 blush 轨。
- 不要把已锁的叠卡改回左字右图，或把窄屏叠卡改回横滑收集。
- 不要搬 underdog 的彩虹字、白狗、产品分栏或拼布深度视差。
