# 口袋教师 · 前端版式短规

画风、色彩和字体以大卫锁定的官网规范为准。本文件只记前端版式，以后写首页及同类营销页都按这里做。

## 首屏

- 英雄插画铺满视口（整屏画布），不要左侧文案栏。
- 标题和 CTA 放在画布下方，不压在图上（顶栏除外）。
- 首屏底部必须有柔和过渡：插画下沿淡入页面底色（`--page`，现为纯白），禁止硬切白边。
- 参考 underdog 的淡出节奏，不要搬他们的角色、粉红侧轨或原句。

## 首屏以下：居中栏，不要平铺

- 首屏以下内容收入居中栏，两侧留轨，不要贴齐视口平铺。
- 侧轨 `--rail: clamp(28px, 8vw, 112px)`，栏宽 `--content: 1080px`。
- 导语长文用更窄的阅读栏 `--measure: 40rem`，栏内左齐（「往中间靠拢」是收栏，不是强制居中排版）。
- 评价卡、叠卡、页脚落在同一条侧轨里。叠卡与评价卡的交互（上拉、横滑）不变，只是落点在栏内。
- 顶栏仍贴视口左右边缘，不受此栏约束。

## 不要做的

- 不要把内容拉满视口宽。
- 不要在页面两侧加粉红或彩色blush轨。
- 不要把已锁的叠卡改回左字右图，或把窄屏叠卡改回横滑收集。
