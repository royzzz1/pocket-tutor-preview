# 口袋教师 · 前端版式短规

画风、色彩和字体以大卫锁定的官网规范为准。本文件只记前端版式，以后写首页及同类营销页都按这里做。

## 首屏

- 英雄插画铺满视口（整屏画布），不要左侧文案栏。
- 标题和 CTA 放在画布下方，不压在图上（顶栏除外）。
- 首屏底部必须有柔和溶白：插画下沿用彩铅笔触溶进白底，可带一点点奶油纸色或 `#D5E6E8`，不要粉色轨，禁止硬切白边。
- 溶白至少约占主图下三分之一（`.canvas::after` 高度约 36%）。
- 导语（标题、说明和按钮）贴在主图溶白下面，不要再把前段撑成单独一屏，也不要在溶白和标题之间再留一大段空白。
- 参考 underdog 的淡出和留白节奏，不要搬他们的角色、粉红侧轨、彩虹字、白狗、产品分栏、拼布深度视差或原句。

## 大底图动效

- 主图、分节插画、收尾插画都保持静止，不要做鼠标分层跟随，也不要为跟随而放大画面。
- 不要做成 underdog 那种拼布深度视差。
- 不要用动效带动主图、分节插画、收尾 banner 或贴片，叠卡也不要进场缩放。不要上粒子、三维或物理。

## 前段文字

- 标题、导语、按钮作为一组整体居中（`--measure: 40rem`），不是「收栏后栏内左齐」。
- 英文标题、导语和正文用 Gochi Hand，中文同一位置用站酷快乐体（ZCOOL KuaiLe，对着 underdog 的 Gaegu 那种圆手写）。标题、导语、正文同一套手写，不要再拆成两套。
- 中文文案用简体（快乐体没有繁体）。章节标题为「寓教于乐，结构清晰」，不要改回繁体，也不要另配繁体字库。
- 前段标题约 64–112px，行距 1.02，字重 400（Gochi / 站酷快乐体都没有粗体）。
- 顶栏和页脚的品名（Pocket Tutor / 口袋教师）也用同一套手写：英文 Gochi Hand，中文站酷快乐体。不要再用 Fraunces 做品名。图标本身没有字，不用改。按钮和语言切换仍用 Atkinson Hyperlegible / Noto Sans SC，不要改成手写。
- 导语略放大，墨色用 `#4A4844`。
- 按钮仍是圆角胶囊，字用 Atkinson / Noto Sans SC，颜色仍是青绿底和墨色描边。

## 首屏以下：居中栏，不要平铺

- 首屏以下内容收入居中栏，两侧留轨，不要贴齐视口平铺。
- 侧轨 `--rail: clamp(28px, 8vw, 112px)`，栏宽 `--content: 1080px`。
- 章节之间大约 72px，下一节标题单独居中出场，再出现该节内容。不要再把各节撑成远离的一屏。评价和「寓教于乐」上下大约 72px。
- 评价卡左右用箭头点击看下一位小朋友，禁止鼠标拖拽或按住往右拉。桌面、窄屏都只露出一张完整卡和下一张的边，不要并排钉死。每张在头像下加名字，站点排字、不画进图。不要搬五星和身份行。三张先用 Leo / 里奥、Maya / 玛雅、Owen / 欧文，并标明是示意评价、并非真实用户来信，换成真实评价后再去掉这句。不做评价墙。
- 演示动画放在溶白后的居中栏、文案下面居中，不要做成左字右视频。片长和预算听 Roy，成片未交前不挂空窗。
- 页脚前通栏铺满收尾 banner（`footer-gifts-banner-wide-21x9-2026-11-13.jpg`，3360×1440）：场面横向铺满，只在边缘溶白。用 21:9 容器 + `object-fit: cover` 挂，不要 `height: auto` 把整图摊开，也不要再挂旧的居中留白版 `footer-gifts-banner-21x9-2026-11-13.jpg`。常年送礼感（不要圣诞帽、圣诞树、雪花），涂鸦不画进图。吉祥物仍是通体奶油小机器、深凹屏，周围礼物和小朋友，允许画小朋友面部，场景里不另画产品，字不进图。
- 左右留白挂彩铅小贴片（纸飞机、棒棒糖、铅笔、小星星，各两姿势，透明底）点成细边，不要进中间、不要挡字和主图、不要铺成墙。窄屏不挂。contact-sheet 不挂。贴片保持静止，不要鼠标跟随。
- 叠卡仍是上拉叠卡，落在同一条侧轨里。插画按原画 16:9 整张放下，不裁、不 scale、不改比例。文案叠在左边留白上（这三张原画为文案留的），不要放到图下白底，也不要重裁或重出。窄屏同样原构图整张挂、字在左白里。文案保持短：标题加一句正文。叠卡不要进场缩放，保持和插画一样静止。
- 顶栏仍贴视口左右边缘，不受此栏约束。

- 个人订购是独立子页 `order.html`，一台 `$199`（中英文都写 `$199`）。版式和字体跟营销站同一套。主页和顶栏的 Order now 指到这页。顶栏右侧是 Sign in（墨色描边胶囊，先挂入口，不接账号；点击只说明账号尚未开放，不要做成真登录）和做成按钮的 Order now（青绿底，指到订购页）。网页版语言切换留在顶栏，放在这两个按钮左侧，不要占最右侧，也不要进页脚。窄屏不展示语言切换，顶栏只留品名和这两个按钮。试一课仍留在主图下的导语区，不再并排进顶栏，并注明这是一课的简短演示、不是直播课堂。先不挂未过的单独主图，也不另画一台产品。付款入口未定前，页上按钮不接支付，并写明订购尚未开放。订购页保留原标题、短导语和定价；下方可补「包含什么 / 付款 / 发货退换和保修」，未公布的条款不要编造。
- 主页在收尾 banner 前加 FAQ，落在同一条居中栏，上下大约 72px，手写字体，不要做成产品分栏或另套字。文案先按已锁事实写，作为草稿等 Roy 过。
- 预览站加 meta description、Open Graph 和 canonical，并用 `noindex`，直到正式域名。分享图暂用已锁主图。logo 和 favicon 等 Roy 选定、大卫过后再挂，先不要把 A/B 稿挂上去。
- 文字入场和按钮按压缩放反馈用官方 Anime.js 4.5.0（自托管 `js/vendor/anime.umd.min.js`）。只动标题、导语、按钮、FAQ 等文字和控件。尊重 `prefers-reduced-motion`。吉祥物或插画的文件动效等图资出 Lottie / Rive、大卫过后再挂。

## 不要做的

- 不要把内容拉满视口宽。
- 不要在页面两侧加粉红或彩色 blush 轨。
- 不要再把叠卡改成图下字，也不要裁切或放大改原画比例，也不要把窄屏叠卡改回横滑收集。
- 不要搬 underdog 的彩虹字、白狗、产品分栏或拼布深度视差。
- 不要再做鼠标跟手拖拽的评价卡交互。
- 不要把标题和正文改回 Atkinson，或标题、正文各用一套字。不要把顶栏品名改回 Fraunces。不要把按钮和语言切换改成手写。
