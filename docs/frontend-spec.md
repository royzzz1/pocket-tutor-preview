# 口袋教师 · 前端版式短规

画风、色彩和字体以大卫锁定的官网规范为准。本文件只记前端版式，以后写首页及同类营销页都按这里做。

## 首屏

- 英雄插画铺满视口（整屏画布），不要左侧文案栏。
- 标题和 CTA 放在画布下方，不压在图上（顶栏除外）。
- 首屏底部必须有柔和溶白：插画下沿淡入页面底色（`--page`，现为纯白），禁止硬切白边。
- 溶白至少约占主图下三分之一（`.canvas::after` 高度约 34%）。
- 溶白结束之后、标题出现之前，要再留一段空白，不要标题马上接上。
- 参考 underdog 的淡出和留白节奏，不要搬他们的角色、粉红侧轨、彩虹字、白狗、产品分栏或原句。

## 首屏以下：居中栏，不要平铺

- 首屏以下内容收入居中栏，两侧留轨，不要贴齐视口平铺。
- 侧轨 `--rail: clamp(28px, 8vw, 112px)`，栏宽 `--content: 1080px`。
- 标题、导语、按钮作为一组整体居中（`--measure: 40rem`），不要在栏内左对齐。
- 章节之间要有独立空白，下一节标题单独居中出场，再出现该节内容。不要把前段和评价卡挤在同一屏。
- 评价卡继续横滑、露出下一张边；桌面不要三张并排铺满。不做评价墙。
- 叠卡仍是上拉叠卡（文案压在画左留白上；窄屏图在上、文案在卡内图下），落在同一条侧轨里。
- 顶栏仍贴视口左右边缘，不受此栏约束。

## 不要做的

- 不要把内容拉满视口宽。
- 不要在页面两侧加粉红或彩色 blush 轨。
- 不要把已锁的叠卡改回左字右图，或把窄屏叠卡改回横滑收集。
- 不要搬 underdog 的彩虹字、白狗或产品分栏。
